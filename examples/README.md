# arda examples

Every file here is **derived from real data already committed to this repo** — GenBank mRNA
records and a sample of VDJdb — and every one is regenerated by a single script:

```bash
python examples/regenerate.py     # rebuilds all committed artifacts
```

`tests/realworld/test_examples.py` re-runs that logic and fails if a committed artifact no
longer reproduces. The previous `example.airr.tsv` silently went stale for four release
rounds — written with 49 AIRR columns when the schema had grown to 83 — because nothing
checked it. Provenance is recorded in [`SOURCES.md`](../SOURCES.md).

---

## 1. Annotate — one real mRNA per locus

```bash
arda annotate -i examples/example.fasta -o examples/example.airr.tsv --organism human
```

[`example.fasta`](example.fasta) holds five real human GenBank mRNA records;
[`example.airr.tsv`](example.airr.tsv) is arda's 83-column AIRR output.

| sequence_id | locus | v_call | d_call | j_call | d_support | cdr3_aa |
|---|---|---|---|---|---|---|
| PZ235980.1 | IGH | IGHV3-9*01 | – | IGHJ6*03 | – | ARDIGAGGFGDNFYFFYYMDV |
| PV083657.1 | IGK | IGKV1-33*01,IGKV1D-33*01 | – | IGKJ5*01 | – | QQYDSLPYT |
| PP196642.1 | IGL | IGLV1-40*01 | – | IGLJ1*01 | – | QSYDSSLSGYV |
| PQ177856.1 | TRA | TRAV12-2*02 | – | TRAJ12*01 | – | AVNGDSSYKLI |
| AF043995.1 | TRB | TRBV28*01 | TRBD1*01 | TRBJ1-4*01 | 0.0465 | ALSRGQAREKLF |

Two things worth reading off this table.

**IGK/IGL/TRA get no `d_call` because they have no D gene.** Not a miss — a VJ locus.

**IGH here gets no `d_call` either, and that is the E-value gate doing its job.** In the
43 nt V..J interior the best hit is `IGHD2-21*01` at score 10, whose E-value is `0.286` —
just above the `_D_MAX_EVALUE = 0.2` operating point. An older arda *did* report
`IGHD2-21*02` for this record, out of a 9 nt window the scaffold projection had collapsed,
where the same 7 nt match carried an E-value of 1.62. A call is not evidence.

`d_support` is the E-value the call is gated on, and it ships in the output so you can
re-threshold downstream.

## 2. Tandem D-D — `d_call` + `d2_call`

```bash
arda annotate -i examples/dd.fasta -o examples/dd.airr.tsv --organism human
```

D-D rearrangements are rare. Scanning all five committed realworld fixtures for a non-empty
`d2_call` finds **six reads out of 7,341**:

| organism | reads | D-D |
|---|---|---|
| human | 2750 | 3 |
| rabbit | 484 | 2 |
| rhesus_monkey | 1500 | 1 |
| mouse | 2093 | **0** |
| rat | 514 | **0** |

[`dd.fasta`](dd.fasta) holds the two human ones.

| sequence_id | locus | d_call | d_support | d2_call | d2_support | np1 | np2 | np3 |
|---|---|---|---|---|---|---|---|---|
| AM408133.1 | TRD | TRDD2*01 | 0.0216 | TRDD3*01 | 0.00721 | CCCCGG | AGCGAGGAGT | CCATCGGG |
| PX612894.1 | IGH | IGHD3-9*01 | 1.96e-06 | IGHD2/OR15-2a*01,IGHD2/OR15-2b*01 | 0.115 | CCCT | CTTCC | GACTC |

`AM408133.1` is the textbook case: TRD is the locus that physiologically joins two D genes,
and `TRDD2 → TRDD3` is in germline 5'→3' order. Its `junction_aa` is
`CALGPRPSYSEELGDTHRADKLIF`.

`PX612894.1` shows the other thing worth seeing: `d2_call` is a **two-allele ambiguity list**.
`IGHD2/OR15-2a*01` and `IGHD2/OR15-2b*01` are byte-identical germlines belonging to different
genes, so a read matching one matches the other at every score. arda reports both rather than
letting an allele-name sort pick a winner.

`np1`/`np2`/`np3` partition the interior exactly: `np1 + D1 + np2 + D2 + np3` reconstructs the
V..J span, byte for byte.

## 3. Junction markup and repair — records with no read behind them

A VDJdb row is a CDR3 amino acid, a V call and a J call. There is nothing to align.

```bash
arda markup -i examples/junctions.tsv -o examples/junctions.markup.tsv \
            --id-col id --d-posterior --report examples/junctions.report.txt --show-ok
```

[`junctions.tsv`](junctions.tsv) holds seven real VDJdb records, one per repair outcome. All
coordinates are **junction space** (Cys104 … Phe/Trp118, both anchors *included*) — the
convention VDJdb's `cdr3` column uses, which is *not* arda's `cdr3` field.

| id | submitted | repaired | v_fix | j_fix | errors |
|---|---|---|---|---|---|
| clean-trb | CASSPLGQAYEQYF | *(unchanged)* | NoFixNeeded | NoFixNeeded | – |
| v-anchor-sub | FLVGPQGSSASKIIF | **C**LVGPQGSSASKIIF | FixReplace | NoFixNeeded | `V sub@0 F>C d=0` |
| j-anchor-missing-F | CAIRDDKII | CAIRDDKII**F** | NoFixNeeded | FixAdd | `J del@8 missing 'F' d=0` |
| j-anchor-extra-G | CATSSPGLASDEQFFG | CATSSPGLASDEQFF | NoFixNeeded | FixTrim | `J ins@15 extra 'G' d=0` |
| reported-not-repaired | CASSSPLLSSDTQYFG | CASSSPLLSSDTQYF | NoFixNeeded | FixTrim | `J sub@9 S>T d=6 (reported, not repaired)`; `J ins@15 extra 'G' d=0` |
| flanking-fr3-trimmed | YFCASPGGIQYFGAG | CASPGGIQYF | FixTrim | FixTrim | `V ins@0 extra 'YF' d=0`; `J ins@10 extra 'GAG' d=0` |
| bad-segment-refused | CAVRSMDSNYQLIW | *(unchanged)* | FailedBadSegment | NoFixNeeded | – |

**`reported-not-repaired` is the one to study.** Two errors are *detected*; only the one
adjacent to the anchor is *applied*. The substitution six residues deep is reported and the
junction left alone, because at that depth a mismatch is as likely to be the real V/N boundary
as a curation error. Detection and repair are separate decisions — see `--max-replace`.

**`flanking-fr3-trimmed`** is a submission that carries framework residues on both flanks —
`YF` before Cys104, `GAG` past Phe118. Both go. arda trims up to `_MAX_TRIM = 3` residues per
flank; a longer one is refused rather than silently swallowed (`YFYFCASSLGGNEQFF` →
`FailedNoAlignment`). Removing residues the germline never explained is a much smaller risk
than *inventing* residues, which is capped separately at `_MAX_FIX = 2`.

**`bad-segment-refused`** cites `TRAV1-2*02`, a real IMGT allele arda ships with no usable
anchor (`status = no_anchor` in `cdr3_anchors.tsv`). The junction comes back untouched and the
record is flagged. The gene's `*01` marks the same junction up cleanly. Flag, never guess.

**Every repair lands on a canonical junction.** `cdr3_repaired` is accepted only if it opens
with Cys104 and closes with Phe/Trp118 — a repair exists to restore the anchors, and everything
downstream trusts the result. So `good` implies canonical, by rule rather than by luck.

On the full 250-row fixture arda reproduces VDJdb's own repair on **all 100 records VDJdb marks
as needing one**, agrees with its `good` / `vCanonical` / `jCanonical` verdict on every row, and
rewrites nothing it should not.

[`junctions.report.txt`](junctions.report.txt) is the human-readable log (`--report`), with a
fix-type cross-tab and a per-record line.

`--d-posterior` adds a D gene inferred from junction *length*: the nucleotide length pins
`insVD + |D surviving| + insDJ`. `clean-trb` (a TRBJ2 J) comes back `TRBD1` at posterior
0.743; `j-anchor-extra-G` comes back `TRBD2` at 0.958. A TRBJ1 record would come back `TRBD1`
at posterior **1.0** — TRBD2 lies 3' of the entire TRBJ1 cluster, so no TRBJ1 rearrangement
can ever have used it.

## 4. Bulk RNA-seq — reads to clonotypes

```bash
arda rnaseq run --r1 examples/rnaseq/reads.fq.gz -p ex -d examples/rnaseq --organism human
```

[`reads.fq.gz`](rnaseq/reads.fq.gz) is 1,035 single-end 150 bp reads (8.9 KB), tiled at stride
4 across twelve real human mRNA — deliberately chosen to span all six loci and to include
records that carry a D. Runs in ~6 s.

```
[arda] map: 925/1035 reads mapped (89.37%); loci={'TRA': 158, 'TRB': 266, 'TRD': 128, 'IGL': 81, 'IGK': 97, 'IGH': 195}
[arda] assemble: 107/112 complete contigs from 176 seeds; rescued 145 reads
[arda] correct: 18 -> 18 clonotypes (0 collapsed) over 306 reads
```

[`clones.tsv`](rnaseq/clones.tsv) has 18 clonotypes; **8 carry a `d_call`**, and one carries a
tandem `d2_call` — the same `TRDD2 → TRDD3` rearrangement as `dd.fasta`, recovered here from
150 bp reads instead of the full mRNA:

| junction_aa | v_call | j_call | locus | d_call | d2_call | d_support |
|---|---|---|---|---|---|---|
| CASSQSGDSYEQYF | TRBV23-1*01 | TRBJ2-7*01 | TRB | TRBD1*01 | | 0.0598 |
| CALGPRPSYSEELGDTHRADKLIF | TRDV1*01 | TRDJ1*01 | TRD | TRDD2*01 | TRDD3*01 | 0.0216 |
| CARDLGYCSNGVCRAPDGTVDYYYYGMDVW | IGHV3-30*08 | IGHJ6*02 | IGH | IGHD2-8*01 | | 2.21e-07 |

D is mapped **once per clonotype**, into its error-corrected junction — not voted over reads.
D is a function of the junction, and a read's copy of it carries sequencing error.

Most TRB clonotypes here get *no* D call. That is expected, not a defect: an ordinary TRB
junction leaves an 11–21 nt interior in which TRBD1 (12 nt, heavily trimmed) scores 5–6
against a `min_score` of 7. Measured call rate for human TRB is ~47 %.

The run also writes `ex.airr.tsv` (mapped reads), `ex.assembled.airr.tsv` and `ex.arda.json`
(timing, peak RSS). Only `clones.tsv` is committed — the others are large, or not reproducible.

## Library

```python
import arda

records = arda.annotate_sequences(
    [("clone1", "GACGTGCAG..."), "CAGGTGCAGCTG..."],   # (id, seq) or bare strings
    seqtype="nt", organism="human",
)
for rec in records:
    print(rec["sequence_id"], rec["v_call"], rec["d_call"], rec["j_call"], rec["cdr3_aa"])
```

Records with no read behind them, and D on a bare junction:

```python
from arda.cdr3fix import markup_cdr3
from arda.annotate.dmap import map_d_junction
from arda.dpost import posterior_d

mk = markup_cdr3("CAIRDDKII", "TRAV12-3*01", "TRAJ30*01", "HomoSapiens")
mk.cdr3_repaired               # 'CAIRDDKIIF'  -- the Phe118 anchor restored
[str(e) for e in mk.errors]    # ["J del@8 missing 'F' d=0"]

map_d_junction("TGTGCTCTTGGG...", "TRDV1*01", "TRDJ1*01", "human").d2_call   # 'TRDD3*01'
posterior_d("CASSPLGQAYEQYF", "TRBV5-1*01", "TRBJ2-7*01", "human").d_call    # 'TRBD1'
```

## Annotating bare germline segments

There is no coverage filter, so a **V-only** or **J-only** query maps to its scaffold and only
the regions inside the query's coverage are returned — a bare V yields `fwr1..fwr3`, a bare J
yields `fwr4`:

```python
from arda.annotate.mapper import annotate_records

recs = annotate_records(
    [("TRBV9*01", v_germline_nt), ("TRBJ2-7*01", j_germline_nt)],
    organism="human", seqtype="nt", strand="forward", map_d=False,
)
```

(mirpy uses exactly this to bake per-allele FR/CDR subsequences into its gene library; see
`tests/synthetic/test_germline_segments.py`.)

## Amino-acid input

```bash
arda annotate -i proteins.fasta -o /tmp/out.aa.airr.tsv --seqtype aa
```

D is mapped on protein too, against each D germline's three translated frames. Useful for IGH
(a call on ~36 % of real records, agreeing with the nucleotide call on 98 % of them), mostly
silent for the TR loci, whose D is too short to survive trimming into protein. `d_germline_*`
and `d_cigar` stay empty there: those offsets index a reading frame, not the germline.
